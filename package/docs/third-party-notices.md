## TailAdmin date picker

The shared Flatpickr date picker in `src/components/date-picker.tsx` adapts the single-date, static-calendar setup from TailAdmin's Next.js template. The FoodStore implementation adds Indonesian localization, validation, mobile support, and scoped theme styles.

Source: https://github.com/TailAdmin/free-nextjs-admin-dashboard/blob/main/src/components/form/date-picker.tsx
